# FOODIE254 🍔

FOODIE254 is a Kenyan food discovery and restaurant recommendation platform.

## Features

- Discover restaurants
- Search for food
- Browse menus
- Filter restaurants
- Restaurant reviews
- Favorites
- User accounts
- Restaurant owner dashboard
- Restaurant recommendations

## Tech Stack

### Frontend
- React
- Tailwind CSS

### Backend
- Flask
- SQLAlchemy
- JWT Authentication

### Database
- PostgreSQL
